# Архитектура

Все времена — по Пекину (UTC+8). DeepSeek работает только в дешёвые часы ([RULES.md](RULES.md)).

```
Сервер Сингапур ── Docker: investor-agent (127.0.0.1:8010, 1 CPU / 1 ГБ)
│
├─ Планировщик (scheduler.py)
│   ├─ 03:00/05:00/07:00  unicorn.prepare  ─┐
│   ├─ 10:00              unicorn.publish   │  DeepSeek: только вне 08:45–12:15 и 13:45–18:15 в будни
│   ├─ каждые 3 ч         radar.run        ─┘
│   └─ 21:30              отчёт о расходах → админу
│
├─ DeepSeek (deepseek.py)
│   ├─ chat/completions с инструментами web_search и fetch_page
│   ├─ Search / Fetch API DeepSeek — поиск и чтение страниц
│   └─ защита: вызов в дорогое время → PeakHoursError → перенос
│
├─ Реестр источников (sources.py) — модель ссылается только на [S1]…, URL подставляет код
├─ SQLite (storage.py) — архив компаний, черновики, алерты, потоки ETF, расходы, блокировки
└─ Telegram + Telegraph (telegram.py)
```

## Школа единорогов

1. **Кандидаты** (`deepseek-flash` + поиск, промт `unicorn_candidates.md`): 4–5 частных компаний с оценкой ≥ 1 млрд $, баллы 0–10 по 5 критериям.
2. **Выбор (код):** исключает архив (Vinted, Whatnot, Brevo и всё опубликованное), отрасли из списка запретов и оценки < 1 млрд $; взвешенный балл 30/25/20/15/10; штраф за повтор отрасли (7 дней), страны (3 дня) и AI подряд.
3. **Исследование и текст** (`deepseek-v4-pro` + поиск, промт `unicorn_school.md`): 11 разделов, раунды, график, медиа — JSON.
4. **Проверка (код):** все разделы, «суть» = 5 предложений + вопрос + правило, русский язык, ≥ 5 реально открытых источников, неизвестные ссылки вычищаются. Одна попытка исправления, иначе — сбой и сообщение админу.
5. **10:00:** страница Telegraph (разделы, раунды, источники) + короткий пост с кнопкой. Компания попадает в архив.

## Инвест радар

1. **Окно:** с прошлой успешной проверки (не больше 12 ч). Блокировка от параллельных запусков.
2. **Снимок рынка (код):** Binance (BTC/ETH/SOL, фандинг, открытый интерес), Yahoo (S&P 500, ES, NDX, RUT, VIX, Brent, WTI, DXY), FRED (доходности 2 и 10 лет), Farside (потоки ETF — агрегатор, «предварительные/итоговые»). Календарь сессий США.
3. **Пороги (код, `config/radar.yaml`):** каждый срабатывает один раз.
4. **Фильтр** (`deepseek-flash`, `radar_gate.md`): есть ли новые события. Нет событий и порогов → `NO_ALERT`, полная тишина.
5. **Алерт** (`deepseek-v4-pro`, `invest_radar.md`): проверка, сценарии, «ПРОСТЫМИ СЛОВАМИ…».
6. **Проверка (код):** русский язык, 3–5 предложений в итоге, открытые источники, 2 независимых издателя для чрезвычайных событий, дубль по ключу события.
7. **Отправка:** запись «ожидает» → Telegram → «отправлен». Неизвестный статус после сбоя не переотправляется. Строка «Не является индивидуальной инвестиционной рекомендацией» добавляется при совете на покупку.

## Секреты

Только в `.env` на сервере. Токен Telegram не попадает в логи и тексты ошибок; `Settings` не печатает ключи.
